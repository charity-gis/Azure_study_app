# Contributing

Please discuss significant changes with Charity Lovi through a repository issue before implementing them. No open-source licence has been selected yet.

1. Review the README, docs/SETUP.md and AGENTS.md.
2. Create a focused feature branch in your own local development workflow.
3. For content changes, cite current Microsoft Learn documentation and identify the exam objective.
4. Keep shared study rules browser-safe and test new behavior, not merely labels or styling.
5. Preserve guest/account isolation, explicit guest imports, ownership protection and the unofficial disclaimer.
6. Do not add paid AI requests without the creator's explicit approval.
7. Run `bun run test` and the checks appropriate to your change; explain what remains unverified.
8. Submit a pull request with the change, rationale, verification and screenshots for visible updates.

Never submit secrets, learner data, official exam dumps or Microsoft logos. Report security problems privately, not as public issues containing exploit details or private data.
